SERVICES

できること

単品のご依頼から、継続のパートナー契約まで。すべて完全リモート、連絡はチャット中心で迅速に対応します。

01

印刷物デザイン（DTP）

チラシ・パンフレット・冊子・カタログなど。企画とレイアウトから、印刷入稿用データの作成まで一貫して対応します。DTP歴16年、入稿事故のないデータ作りが強みです。

02

Webデザイン・コーディング

WebサイトやLPのデザインと、HTML / CSS / JavaScript による実装。デザインだけ、実装だけのご依頼も可能です。スマホ表示まで丁寧に作ります。

03

インタラクティブ・Webツール開発

Canvas / WebGL を使った「触って楽しい」演出や、業務を軽くするブラウザツール。ライブラリに頼らない自作エンジンで、軽くて長持ちする実装をします。

04

文章・編集・校正

記事や原稿の推敲、構成の改善、誤字脱字のチェック。エッセイやブログの執筆実績もあり、「読み手が疲れない文章」を意識して整えます。

ABOUT

仕事への考え方

私の専門は「手続き的設計」——工程を再現できるところまで分解して、仕組みにすること。目的はいつも同じで、使う人が疲れない道具を作ることです。

MY MOTTO人が気持ちよく使える道具を作ること。美しい色、直感的な操作、気持ちのよい動き、そしてなによりも、疲れにくさ。

デザインシステム自体を、道具にする

デザインの約束事は、守る人の注意力に頼るほど漏れていきます。私は約束事そのものを「実行できる道具」に変えます。パラメータが、毎回同じ結果を保証するからです。

その再現性は「床」。天井は人の自由です。すべてのパラメータは上書きできるままにしておく——システムの確実さのために、人の自由度は削りません。

AIに実装させ、判断は自分で持つ

AIエージェントを実装のリソースとして指揮し、成果物はすべて自分で読んで判断してから出します。「説明できないものは出さない」が私のルールです。

AIが速くするのは手であって、判断ではありません。1人とスマホ1台と電車の移動時間で、このページの全エンジンが生まれました。
