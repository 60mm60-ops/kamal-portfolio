ABOUT

私について

活動名「かまる」です。※本名は契約時にお伝えしております。
奈良在住のデザイナー／開発者です。

印刷物デザイン（DTP）16年の経験をもとに、チラシ・カタログ・展示パネルなどの印刷物から、Webサイト、ブラウザで動く業務ツールまで制作しています。

勤務先・クライアントの制作物は守秘のため実物を載せることができませんが、対応可能な業務と仕事の進め方はこのページにまとめています。ご依頼は完全リモートで、全国から承っています。

SERVICES

対応可能な業務

1点だけのご依頼から、継続のご相談まで。すべてリモート対応です。ご連絡への返信は、原則1営業日以内を心がけています。

01

印刷物デザイン（DTP）

チラシ・パンフレット・冊子・カタログなど。企画とレイアウトから入稿データの作成まで、一貫してお受けします。勤務先・クライアントの制作物は守秘のため、実物を載せることができません。

02

Webデザイン・コーディング

WebサイトやLPのデザインおよび、HTML / CSS / JavaScript での実装。デザインだけ、実装だけでも可能です。保守・メンテナンスは別途ご相談ください。

03

インタラクティブ・Webツール開発

Canvas / WebGL を使った「触って楽しい」演出や、業務を軽くするブラウザツール。エンジンから自作するので、ライブラリの都合に振り回されず、軽くて長く使えるものになります。業務改善系・DXアプリも制作可能です。

04

文章・編集・校正

記事や原稿の推敲、構成の見直し、誤字脱字のチェック。「読み手が疲れない文章」になるよう整えます。
